# Oppimispäiväkirja 2

## Mitä opin?
- Opin siirtymään git checkout komenolla haarojen välillä, sekä ymmärsin miten paikallinen ja etärepositorio liittyvät toisiinsa
- Opin tekemään committeja eri haaroihin
- Harjoittelin haarojen yhdistämistä git merge -komennolla ja opin, missä tilanteissa haarat kannattaa yhdistää oletushaaraan
- Opin kloonaamaan projektin GitHubista itselleni ja viemään myös oman projektin GitHubiin
- Ymmärsin myös, miten voin hakea toisen henkilön tekemiä muutoksia GitHubista git fetch -komennolla ja tuoda ne omaan työhöni
## Mikä oli helppoa?
- Haaran vaihtaminen git checkout komennolla oli helppoa kun vain ymmärsi, missä haarassa kulloinkin olin
- Projektin vieminen GitHubiin tuntui melko yksinkertaiselta
- Git status -komento auttoi hamottamaan mitä tällä hetkellä tapahtuu ja mitä tulisi tehdä seuraavaksi
## Mikä oli vaikeaa?
- Välillä haarojen yhdistämiset eli merge aiheutti haasteita ja olivat haastavia ymmärtää
- Yhdistämiset avasivat VS Coden automaattisesti ja en aluksi tiennyt mitä sille pitää tehdä
## Mikä auttoi minua oppimaan ja miten selvitin esteet?
- Selvitin esteitä googlettamalla virheilmoituksia, mikä auttoi ymmärtämään mistä gitin antaman virheet voisivat johtua
- Käytin Chat GPT:tä apuna silloin, kun googlesta tai oppimateriaalista ei löytynyt vastausta ja apua kysymyksiini
- Jälleen kokeileminen auttoi. Kun prosessi toistui moneen kertaan, alkoi kaikki hahmottua selkeämmin.


## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git clone | lataa projektin GitHubista omalle koneelle |
| cd | siirtyy haluttuun kansioon |
| git checkout| siirtyy haluttuun haaraan|
| git add | lisää tiedoston Git-hallintaan |
| git commit | Tallentaa muutokset versionhallintaan |
| git push | työntää muutokset Git hubiin |
| git merge origin/master | yhdistää etähaaran muutokset lukutilassa |
| git fetch| hakee GitHubista uudet muutokset |
| git status| Näyttää repositorion tilan |
